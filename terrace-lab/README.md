# Terrace lab (Solstice beta)

Paris's seating permits drawn as their footprint along the nearest façade, with skylines measured
at points over them, and the points where Solstice measures the sun of OpenStreetMap places.
Read by beta builds of the app only (`src/lib/terrace-lab.ts`), built by
`scripts/build-terrace-lab.ts` in the app's repository.
